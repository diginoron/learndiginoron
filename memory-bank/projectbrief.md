# Project Brief — DigiNoron (diginoron.com)

## Goal
Official website of DigiNoron AI Academy: attract, educate and convert Persian/English/Arabic-speaking visitors into course registrations (kids/teens/corporate) and enterprise AI project inquiries.

## Scope
- Multilingual marketing site (en default at root, fa, ar) built with Next.js App Router.
- Sections: home, blog/magazine (SEO pillar articles), courses + held courses, services, about, contact.
- All content is data-driven (TypeScript data files), no CMS/DB.

## Core Requirements
- SEO-first bilingual content production (use `seo-content-masterclass` skill).
- Locale-correct internal links and hreflang alternates (`getAlternateUrls`).
- Auto-generated sitemap & JSON-LD structured data.
- CTAs funnel readers to the contact page (`/contact`, `/fa/contact`).
